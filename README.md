# Classic Textiles Website

A modern and responsive corporate website developed for a premium textile manufacturing business. The website showcases the company's products, services, catalog, gallery, and business information while maintaining a clean and professional user experience.

## Live Demo

https://classic-textiles-website1.vercel.app/

---

## Features

- Modern corporate UI
- Fully responsive design
- Animated Hero Section
- About Company
- Product Categories
- Product Detail Pages
- Gallery
- PDF Catalog
- Contact Page
- Google Maps Integration
- WhatsApp Quick Contact
- Scroll to Top Button
- Smooth Page Animations
- Mobile Friendly Navigation
- SEO Friendly Structure

## Installation

Clone the repository

```bash
git clone https://github.com/mahamsiddique-2020/classic-textiles-website.git
```

Navigate into the project

```bash
cd classic-textiles-website
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
